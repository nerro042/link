# My Links

A colorful, responsive "link in bio" website built with Vite, TypeScript, and Tailwind CSS. Share all your important links in one place with beautiful gradient backgrounds.

## Features

- 🎨 **Colorful gradients** - Links with vibrant, rotating gradient backgrounds
- ➕ **Add links dynamically** - Create new links with titles and URLs
- 🗑️ **Delete links** - Hover over links to reveal delete buttons
- 💾 **Persistent storage** - Links are saved to localStorage
- 📱 **Responsive design** - Works perfectly on mobile and desktop
- ⚡ **Fast development** - Powered by Vite with HMR

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Usage

1. Enter a link title (e.g., "My Portfolio")
2. Enter the URL (e.g., "https://example.com")
3. Click "Add Link"
4. Your links will appear below with beautiful gradient backgrounds
5. Hover over any link to see the delete button

## Build

To build for production:
```bash
npm run build
```

## Preview

To preview the production build:
```bash
npm run preview
```
